\section{Transpositions and Length}

In the last lecture, we saw that every permutation $p \in S_n$ can be decomposed into disjoint cycles. We also introduced the following notion:

\begin{definition} A simple transposition in $S_n$ is a permutation of the form $s_i:= (i\ i+1)$ for $i=1, 2, \ldots, n-1$.  \end{definition}

For example, in $S_3$ the transpositions $s_1=(1\ 2)$ and $s_2=(2\ 3)$ are simple, but $(1\ 3)$ is not.

Using a variant of the bubble sort idea, one can now prove

\begin{theorem} Every $p \in S_n$ can be written as a product of simple transpositions $s_i$ for $i=1, \ldots, n-1$. The minimal number of such transpositions needed to write $p$ is called the (Coxeter) length of $p$ and is denoted as $\ell(p)$.
\end{theorem}

\begin{warningbox}
	The length of a \textit{simple} transposition $(i\ i+1)$ is always one, but this isn't the case for an arbitrary transposition $(a\ b)$. For example, take
	\be
	\tau=(1\ 3)\in S_3.
	\ee
	In one-line notation,
	$\tau=[3,2,1]$, and bubble sort gives
	\be
	[3,2,1]
	\xrightarrow{\ s_1\ }[2,3,1]
	\xrightarrow{\ s_2\ }[2,1,3]
	\xrightarrow{\ s_1\ }[1,2,3].
	\ee
	Thus $\tau$ has length $3$, not $1$. Equivalently,
	\be
	\tau=s_1s_2s_1.
	\ee
\end{warningbox}


\section{Inversions and length}

\newcommand{\inv}{\mathrm{inv}}
\begin{definition}[Inversion]
Let $p\in S_n$. An \emph{inversion} of $p$ is a pair $(i,j)$ such that
$1\leq i<j\leq n$ and $p(i)>p(j)$. The \emph{inversion number} of $p$ is
the number of such pairs:
\be
\inv(p):=\#\bigl\{(i,j):1\leq i<j\leq n,\ p(i)>p(j)\bigr\}.
\ee
\end{definition}

\begin{example}
Consider $p \in S_4$ the permutation corresponding to the unordered list $[3,1,4,2]$. Its inversions correspond to the pairs
\be
(1,2),\qquad (1,4),\qquad (3,4).
\ee

Therefore
\be
\inv(p)=3.
\ee
For comparison, $(2,4)$ is not an inversion because $p(2)=1<p(4)=2$.
\end{example}


\begin{lemma}
If $p\in S_n$ and $s_i=(i\ i+1)$ is a simple transposition, then
\be
\inv(ps_i)=
\begin{cases}
\inv(p)+1, & \text{if }p(i)<p(i+1),\\
\inv(p)-1, & \text{if }p(i)>p(i+1).
\end{cases}
\ee
In particular, $\inv(ps_i)$ differs from $\inv(p)$ by exactly one.
\end{lemma}
\begin{proof} Let $I(p):= \bigl\{(i,j):1\leq i<j\leq n,\ p(i)>p(j)\bigr\}$ be the set whose cardinality is the inversion number. Then we want to compare $I(p)$ with $I(p s_i)$, i.e., we want to compare the number of inversions of the list corresponding to $p$ and that corresponding to $ps_i$ (the list obtained from $p$ by swapping the $i$-th and $(i+1)$-st entries).  If $p(i) > p(i+1)$, then $ps_i$ corresponds to a `desirable' move from the bubble sort perspective, in that it moves the list closer to being in order. Hence we expect the number of inversions to go down. 

More precisely, if $1 \leq u < v < i$, then the operation $p \mapsto ps_i$ does nothing to the first $i-1$ elements of the list, so $(u, v)$ belongs to $I(ps_i)$ if and only if it belongs to $I(p)$. If $i+1 < u < v \leq n$, again as $p \mapsto ps_i$ does nothing to the entries after $i+1$ in the list, $(u, v)$ has the same inversion status in $I(p)$ and $I(p s_i)$. The remaining pairs are handled as follows.

\begin{enumerate}
	\item If $u < i$ and $v > i+1$, then the operation $p \mapsto ps_i$ does not change $p(u)$ or $p(v)$, so again $(u, v)$ belongs to $I(p s_i)$ if and only if it belongs to $I(p)$.
	
	\item Consider $(i, i+1)$. Now clearly depending on whether we are in the case $p(i) < p(i+1)$ or $p(i)> p(i+1)$, the pair will either appear or disappear respectively in $I(ps_i)$.
	
	\item If $u=i$ and $v=i+1+h$ with $h>0$, then $(i, i+1+h) \in I(p)$ if and only if, after the swap of the $i$-th and $(i+1)$-st entries, we have $(i+1, i+1+h) \in I(p s_i)$. Similarly, $(i+1, i+1+h) \in I(p)$ if and only if $(i, i+1+h) \in I(p s_i)$. Thus the total number of inversions contributed by these two pairs is unchanged.
	
	\item If $u<i$, then similarly $(u,i) \in I(p)$ if and only if $(u,i+1) \in I(p s_i)$, and $(u,i+1) \in I(p)$ if and only if $(u,i) \in I(p s_i)$. Again the total number of inversions contributed by these two pairs is unchanged.
\end{enumerate}

Thus the only change in the total number of inversions comes from the pair $(i,i+1)$: the number increases by one if $p(i)<p(i+1)$ and decreases by one if $p(i)>p(i+1)$, as claimed.
\end{proof} 

\begin{example}
For the permutation $p=[3,1,4,2]$ above, we have $\inv(p)=3$. Since
$p(1)>p(2)$, right multiplication by $s_1$ decreases the inversion number:
\be
ps_1=[1,3,4,2],
\qquad
\inv(ps_1)=2.
\ee
On the other hand, $p(2)<p(3)$, so right multiplication by $s_2$ increases it:
\be
ps_2=[3,4,1,2],
\qquad
\inv(ps_2)=4.
\ee
Thus this example illustrates both cases of the lemma.
\end{example}

\begin{theorem}
For every permutation $p\in S_n$, its Coxeter length is equal to its inversion
number:
\be
\ell(p)=\inv(p).
\ee
\end{theorem}

\begin{proof}
Choose a shortest expression $p=s_{i_1}\cdots s_{i_{\ell(p)}}$. Starting from
$\id$ and multiplying by these simple transpositions one at a time, the lemma
shows that the inversion number changes by exactly one at each step. Since
$\inv(\id)=0$, it follows that $\inv(p)\leq\ell(p)$.

Conversely, use the bubble-sort factorization from Theorem~1.1. Each step
swaps an adjacent pair $p(i)>p(i+1)$, so the lemma shows that it decreases the
inversion number by exactly one. The process ends at the identity, whose
inversion number is zero, and therefore uses exactly $\inv(p)$ simple
transpositions. Hence $\ell(p)\leq\inv(p)$, proving the equality.
\end{proof}
